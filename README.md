# Pet Breed Classifier 🐶🐱

A deep learning-based web application that predicts cat and dog breeds from uploaded images using a Convolutional Neural Network (CNN).

## 🚀 Features

* Upload pet images
* Real-time breed prediction
* Confidence score display
* Mobile-friendly Streamlit interface
* Deep learning inference with PyTorch

## 🧠 Tech Stack

* Python
* PyTorch
* Streamlit
* Torchvision
* PIL
* CNN (Convolutional Neural Network)

## 📂 Dataset

Oxford-IIIT Pet Dataset containing 37 cat and dog breeds.

## ⚙️ Model

Custom CNN trained on image classification tasks with GPU acceleration using Google Colab (Tesla T4).
